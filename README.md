## 关于我

我是袁智，2027 届电子信息工程本科生，就读于中国地质大学（北京），目前在 360 搜索与智能应用事业部担任 AI 产品经理实习生。

我参与的是 360 搜索及浏览器场景中的「问AI」产品，日均提问约 150 万次，峰值约 175 万次。工作中主要接触 AI 搜索、Agent、多轮交互、任务执行与文件成果交付、产品评测和商业化。

相比只输出 PRD，我更关注如何借助 AI 把产品工作继续向原型、实验、评测和实际交付延伸。因此也会通过 AI Coding 和个人项目持续验证上下文工程、多 Agent 协作与 AI 产品可靠性。
