## 我解决的问题

- **AI 搜索与多轮交互**：从真实 Query、用户行为和反馈中识别需求，设计搜索承接、需求表达、上下文追问和连续服务；
- **Agent 与任务交付**：把任务理解、工具调用、执行状态、文件产物、结果校验和异常处理组织成完整链路；
- **评测与质量迭代**：结合场景评测、模型比较、程序校验、人工复核和 Bad Case 归因推动产品决策；
- **数据与实验**：使用 Python、SQL、埋点和 A/B 实验验证产品效果，不用单一点击指标替代整体价值；
- **AI Coding 与交付**：将产品判断推进到可运行 Demo、业务前端、验证脚本和上线验收。
